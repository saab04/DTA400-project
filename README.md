# Simulation

Make sure you have ns-3 installed and configured in a Linux environment.
`ns-3.48` was used for this simulation.

1. Place the simulation file `wifi-ht-project.cc` inside your ns-3 `scratch` directory.

2. Place the shell script file `run_all.sh` inside your ns-3 root directory, `/ns-3.xx`.

3. Run the simulation:
```
chmod +x run_all.sh
./run_all.sh
```

Simulation results are saved as XML files inside a generated `output` folder.
